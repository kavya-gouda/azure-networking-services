# Azure Bastion

- No need for public IP addresses on VM
- Connect to VM using its private IP
- Connect to the VM using RDP and SSH
- Connect with Azure CLI or portal with TLS
- Connect to VM within same peered VNET
- Support multi-user

## Bastion in Hub and Spoke model

- Bastion is typically deployed within the Hub
- Bastion provides connectivity to all VM;s within the spokes
- Bastion can scale out to support multiple concurrent sessions

<img width="757" height="681" alt="image" src="https://github.com/user-attachments/assets/031847e5-ad4c-4b6d-a4aa-f270b659061c" />

## Bastion and on-prem
-  Bastion enables connection to on premises VM's
-  Uses IP-Based connection
-  Workes with expressRoute or VPN site-to-site connection
-  Requires the standard SKU tier
